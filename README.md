# 🌴 Oil Palm Ripeness Detection using YOLOv8

## 📌 Overview
Project untuk mendeteksi tingkat kematangan buah kelapa sawit menggunakan YOLOv8 dengan deploy menggunakan Streamlit.

---

## 🚀 Features
- Upload image or video prediction
- YOLOv8 object detection
- Streamlit interface
- Ripeness classification

---

## 🧠 Model Classes
| Class | Description |
|---|---|
| Mentah | Unripe |
| Mengkal | Semi-ripe |
| Matang | ripe |

---

## 📊 Model Performance

| Metric | Score |
|---|---|
| Precision | 97% |
| Recall | 95% |
| mAP50 | 98% |
| mAP50-95 | 89% |
